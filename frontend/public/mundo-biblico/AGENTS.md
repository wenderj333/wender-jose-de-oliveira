# Project: Mundo Bíblico: Pequenos Heróis

- **Summary**: A safe, non-violent Christian adventure game for children aged 3-10. Players explore Biblical environments, complete simple tasks, and collect stamps in their "Passaporte Bíblico".
- **Core Loop**: Explore (Garden/Oasis) -> Interact/Task -> Reward (Stamps) -> Progress.
- **Key Modules**:
    - `main.js`: Core game loop, Canvas rendering, entity management, and UI logic.
    - `index.html`: Styles, game container, and overlay UI (Start screen, Passport, Dialog).
- **Assets**:
    - `assets/garden_background.webp`: Lush Eden environment.
    - `assets/oasis_background.webp`: Golden desert oasis.
    - `assets/hero_child.webp`: Main player character.
    - `assets/lamb_sprite.webp`: Friendly lamb NPC.
    - `assets/bible_passport_icon.webp`: UI for the progress tracker.
    - `assets/sigo_com_fe_seal.webp`: Quality badge and stamp image.
- **Audio**:
    - `assets/audio/peaceful_adventure_music.mp3`: Loopable background music.
    - `assets/audio/sparkle_success_sfx.mp3`: Reward sound effect.
    - `assets/audio/soft_tap_ui_sfx.mp3`: UI interaction sound.
- **Controls**: Touch or click to move the character and interact with objects (apples, animals).
- **Validation**: Project uses ES modules and clean browser APIs. Final validation and smoke test pending.
