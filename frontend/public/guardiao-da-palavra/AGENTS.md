# Guardião da Palavra: O Desafio dos Pergaminhos

## Summary
A biblical educational game where the player acts as a scribe protecting ancient manuscripts. The core loop involves solving biblical challenges (quizzes, event ordering, verse completion) across thematic phases to unlock historical knowledge.

## Project Structure
- `index.html`: Main layout, styles, and entry point.
- `main.js`: Game controller, UI orchestration, and challenge logic.
- `game.js`: Challenge definitions for Phase 1.
- `audio.js`: Audio management (ambient music and SFX).
- `art_direction.md` & `sound_direction.md`: Guidance for visual and audio style.

## Assets
- `assets/scribe_desk_bg.webp`: Background desk scene.
- `assets/ancient_parchment_ui.webp`: Main UI scroll.
- `assets/golden_seal_icon.webp`: Success icon.
- `assets/audio/ancient_ambience.mp3`: Loopable ambient music.
- `assets/audio/parchment_unroll.mp3`: Interaction sound.
- `assets/audio/divine_success.mp3`: Success chime.

## Controls
- **Mouse Click**: Select answers, submit forms.
- **Drag and Drop**: Reorder items in ordering challenges.
- **Keyboard**: Type missing words in verse challenges.
- **Mute Button**: Toggle sound in the top right.
